## 一、整体架构

```
感知层（相机 + IMU + 激光雷达）
        ↓
决策层（有限状态机，每个赛段一个状态）
        ↓
控制层（LCM 指令 → cyberdog_control）
```

- 通信：LCM（运动控制）+ ROS2 topic（传感器数据）
- 视觉：OpenCV（颜色检测）+ YOLOv8（目标检测）
- 语音：espeak / pyttsx3
- 开发语言：Python 3.8

## 三、各赛段技术方案

### 赛段一：石径探路

**难点**：石板高5cm、间隔20cm；弯道需要识别黄线转向。

**方案**：
- 步态：`gait_id=9`（小跑），速度 0.3 m/s，`step_height` 设为 0.12（抬高腿避免绊石板）
- 弯道检测：前置摄像头检测黄色边线（RGB: 255,255,0），计算赛道中心偏差，PID控制转向

```python
# 黄线检测核心逻辑
hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
yellow_mask = cv2.inRange(hsv, (25, 100, 100), (35, 255, 255))
# 分别找左右黄线，计算中心偏差
error = lane_center_x - image_width / 2
vyaw = -Kp * error  # PID 转向输出
send_cmd(MODE_LOCOMOTION, GAIT_TROT, vx=0.3, vyaw=vyaw)
```

### 赛段二：荒野寻珠

**难点**：16个球（4行4列）中找4个橙色球（每行每列各1个），撞击后继续找。

**方案**：
- 颜色检测：HSV范围 H:10-25, S:150-255, V:150-255
- 搜索策略：按 R1→R2→R3→R4 行顺序扫描，发现橙色球对准后直行撞击
- 撞击判定：IMU检测碰撞震动，或目标球消失出视野，视为成功
- 撞完后退回通道中线，继续扫描下一行
- 4个球全部撞完后，识别左上角出口（黄线缺口），驶出

```python
# 橙色球检测
orange_mask = cv2.inRange(hsv, (10, 150, 150), (25, 255, 255))
contours, _ = cv2.findContours(orange_mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
if contours:
    largest = max(contours, key=cv2.contourArea)
    (cx, cy), radius = cv2.minEnclosingCircle(largest)
    # 对准球心后前进撞击
    error = cx - image_width / 2
    vyaw = -Kp * error
    send_cmd(MODE_LOCOMOTION, GAIT_TROT, vx=0.3, vyaw=vyaw)
```

### 赛段三：曲道冲锋

**难点**：S形赛道，不能踩线。

**方案**：
- 复用赛段一的黄线跟踪算法
- 速度降至 0.25 m/s，提高转向响应灵敏度
- 赛道净宽100cm，机器狗宽约30cm，容错空间充足

### 赛段四：深隧寻珍（最复杂赛段）

**难点**：识别6种物体，完成对应交互，同时避障。

#### 目标物体识别与交互

| 目标 | 识别方法 | 交互动作 | 语音播报 |
|------|----------|----------|----------|
| 大桶可乐 | YOLOv8自定义模型 | 直行撞倒 | "识别到可乐瓶" |
| 橙色球（高60cm） | HSV颜色检测 | 撞击晃动 | "识别到橙色小球" |
| 足球 | YOLOv8或颜色+形状 | 连续撞击入门 | "识别到足球" |

#### 障碍物识别与避障

| 障碍 | 识别方法 | 避障动作 | 语音播报 |
|------|----------|----------|----------|
| 限高杆（红色，高40cm） | 红色HSV检测 | 降低body_height通过 | "识别到限高杆" |
| 无法跨越障碍物（方块） | YOLOv8或深度估算 | 绕行（借道虚线） | "识别到无法跨越障碍" |

#### 语音播报实现

```python
import subprocess
def speak(text):
    subprocess.Popen(['espeak', '-v', 'zh', text])
# 示例
speak('识别到可乐瓶')
```


### 赛段五：孤梁稳渡

**难点**：独木桥宽度有限，需精确走直线；越过虚线后跳下不碰桥。

**方案**：
- 切换慢速小跑（vx=0.15），用IMU的roll角反馈做平衡修正
- 前置摄像头检测独木桥边缘，保持居中行走
- 白色虚线检测：四足越过后触发跳跃
- 跳跃：加速冲出（vx=0.8，持续0.3s）或使用jump动作

```python
# 独木桥居中控制
roll = imu_data.rpy[0]  # 横滚角
vy_correction = -Kp_roll * roll  # 横向修正
send_cmd(MODE_LOCOMOTION, GAIT_TROT, vx=0.15, vy=vy_correction)
```

### 赛段六：撷金建功

**方案**：
- YOLOv8定位足球，对准后加速冲刺踢出
- 检测终点圆圈（地面标记），减速进入圆圈
- 发送 `mode=0`（passive）趴下，比赛结束

```python
# 踢球
send_cmd(MODE_LOCOMOTION, GAIT_TROT, vx=0.8, duration=300)  # 加速冲刺
time.sleep(0.3)
send_cmd(MODE_LOCOMOTION, GAIT_TROT, vx=0.0)  # 停止
```

## 四、状态机框架

```python
from enum import Enum

class Stage(Enum):
    INIT        = 0
    STAGE1_PATH = 1   # 石径探路
    STAGE2_BALL = 2   # 荒野寻珠
    STAGE3_CURVE= 3   # 曲道冲锋
    STAGE4_HUNT = 4   # 深隧寻珍
    STAGE5_BRIDGE=5   # 孤梁稳渡
    STAGE6_KICK = 6   # 撷金建功
    FINISH      = 7

class RaceController:
    def __init__(self):
        self.stage = Stage.INIT
        self.lcm = lcm.LCM("udpm://239.255.76.67:7671?ttl=255")

    def run(self):
        self.stand_up()
        while self.stage != Stage.FINISH:
            if self.stage == Stage.STAGE1_PATH:
                self.run_stage1()
            elif self.stage == Stage.STAGE2_BALL:
                self.run_stage2()
            # ... 以此类推

    def transition(self, next_stage):
        print(f"赛段切换: {self.stage} → {next_stage}")
        self.stage = next_stage
```

## 七、优先级

**必须完成（保底得分）**
- 赛段一：不可跳过，必须稳定通过
- 赛段三：纯运动控制，技术难度低，复用赛段一代码

**重点投入（高分项）**
- 赛段二：橙色球检测相对简单，分值较高
- 赛段四：最复杂但分值最高，重点攻关

**时间不够时的保守策略**
- 赛段五：慢速通过，不追求速度
- 赛段六：能踢出去就行，不追求精准
